# Ebdaa

Bilingual (Arabic / English) Next.js 16 website for Ebdaa. Node.js 20.9 or newer is required.

```sh
npm ci
npm run dev
```

Production checks and preview:

```sh
npm run lint
npm run build
npm run start
```

## Public URL and SEO

The canonical public origin defaults to `https://ebdaa-one.vercel.app`. Set
`NEXT_PUBLIC_SITE_URL` to an absolute public origin if the domain changes, then
rebuild. `NEXT_PUBLIC_BASE_URL` is not used for SEO, so a local development URL
cannot accidentally appear in production metadata.

Arabic and English pages are prerendered at build time. SEO configuration lives
in `lib/site.ts` and `lib/metadata.ts`: localized titles, descriptions, keywords,
canonical URLs, hreflang, Open Graph, Twitter cards and Google verification.
Alternate language links are generated by metadata and the sitemap; automatic
proxy links are disabled to avoid conflicting localhost or preview URLs.
`components/seo/StructuredData.tsx` supplies Organization, WebSite and WebPage
JSON-LD using the business information already displayed on the site.

Sharing images: `/og-image-ar.png` and `/og-image-en.png` (1200 × 630).
Icons: `/favicon.ico`, `/apple-touch-icon.png`, `/icon-192.png`, `/icon-512.png`.
The manifest is served at `/manifest.webmanifest`.

## Google Search Console and Analytics

After deploying:

1. Verify the URL-prefix property `https://ebdaa-one.vercel.app/` in Search Console.
   Both the Google verification meta tag and the original verification file at
   `/googledb9beca33381b118.html` are included.
2. Submit `https://ebdaa-one.vercel.app/sitemap.xml`.
3. Request indexing of `/ar` and `/en` using URL Inspection.
4. Check Analytics Realtime for measurement ID `G-XYQLS2TJ5M`.

Google Analytics queues configuration after hydration and loads the tag during
browser idle time in production only. Google enhanced
measurement handles browser history changes; avoid adding a second GA snippet
or duplicate page-view tracking. If changing the domain, update the Search
Console property and the Analytics web stream as well.

Metadata and sitemaps help crawlers discover and understand content; they do not
guarantee indexing or ranking. Google ignores the keywords meta tag.

## Performance and accessibility

Responsive image sizes, lazy loading below the fold, optimized source images,
and eager high-priority hero loading reduce image traffic. Reveal effects use CSS transitions and a shared viewport
observer; hero text
starts animating before hydration. Existing visual styles, movement, easing and
animation timing are preserved. The original loading screen covers the main
content and footer together to prevent a streaming layout shift. Forms have hidden labels and
associated validation errors, icon controls have localized accessible names,
and the mobile menu supports Escape and closes after navigation. A keyboard
skip link and focus outlines allow navigating to the main content.

The final local Lighthouse results and browser checks are recorded in
[docs/seo-audit.md](docs/seo-audit.md).

The contact and subscription APIs also require the existing Supabase environment
variables. Never commit `.env.local` or secret credentials.
